# Whisper Tray

Локальная транскрибация звонков на Windows. Приложение живёт в трее, замечает активный аудиосеанс поддерживаемого клиента, предлагает начать запись и дописывает Markdown-транскрипт прямо во время разговора.

## Структура

- `ui/WhisperTray` — WPF-интерфейс, трей, запись микрофона и системного звука.
- `whisper/WhisperEngine` — загрузка модели и вызов Whisper через whisper.cpp.
- `models` — локальные модели. Выбранная модель загружается сюда при первой записи.
- `transcriptions/YYYY-MM-DD` — результаты с именами `YYYY-MM-DD_HH-mm-ss.md`.
- `.tmp/recordings` — незавершённые записи. После успешного распознавания WAV удаляется.

## Запуск

Нужны Windows 11, .NET 10 и CUDA Toolkit 13.0.1 или новее. Установленный драйвер NVIDIA сам по себе не заменяет CUDA Toolkit. Без CUDA приложение откатится на CPU и будет работать заметно медленнее.

```powershell
dotnet run --project .\ui\WhisperTray\WhisperTray.csproj
```

Первая запись запускает фоновую загрузку выбранной модели. Запись начинается сразу. Микрофон и системный звук распознаются отдельно и помечаются как `Я` и `Собеседник`. После десяти секунд приложение ждёт короткую естественную паузу и передаёт завершённый фрагмент одной загруженной модели, поэтому слова не разрезаются на границе. При непрерывной речи обновление файла откладывается до следующей паузы. Файл в `transcriptions/YYYY-MM-DD` создаётся при старте и пополняется во время разговора. После остановки приложение обрабатывает последний фрагмент и добавляет время завершения.

Для параллельной помощи можно открыть в Codex отдельную сессию и указать путь к текущему Markdown-файлу, например: «Читай этот файл каждые 15 секунд, проверяй факты из новых реплик и предлагай короткие подсказки для разговора».

Сейчас подсказка о звонке работает для Teams, Telegram, Яндекс Телемоста и KTalk, если приложение создаёт активный аудиосеанс. Браузерные звонки и календарь не определяются. Запись всегда начинается только после нажатия пользователем.

Перед записью следует предупредить участников звонка, если это требуется правилами компании или законом.
